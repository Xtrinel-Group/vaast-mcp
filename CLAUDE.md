# CLAUDE.md

This repository is public. Anything committed here, including commit
messages and pull request text, is visible to everyone.

## Commits and pull requests

- No AI attribution lines in commit messages or pull requests (no
  `Co-Authored-By:` lines for AI tools).
- No "Generated with ..." footers or similar tool references in commits,
  pull requests, issues or release notes.
- Write commit messages and PR descriptions plainly, as a developer would,
  describing the change and why.
- Don't reference internal plans, internal version roadmaps, customer
  names or unreleased features.

## Code comments

- Keep comments short and plain. Explain why, not what the code already says.
